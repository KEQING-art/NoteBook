文件
{///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
1
创建一个文件
touch 文件名.文件类型   //创建一个空文件
echo"要写入的内容“文件名.文件类型  //创建一个带有初始内容的文件

创建一个空的文件夹
mkdir 文件名 

进入文件
cd /d 进入D盘
cd project 进入磁盘内的文件夹
cd .. （返回上一级目录（可以连用））
cd - （返回之前所在目录）

删掉文件
rm -rf 文件名  （删掉文件）

2
git add
它的作用是将当前工作目录下的所有变动（包括新增、修改和删除的文件）一次性添加到 Git 的暂存区（Staging Area）。

将单个文件添加到缓冲区
git add 文件名.文件类型

将多个文件添加到缓冲去
git add 文件名.文件类型 文件名.文件类型

将一个目录添加到缓冲区
git add 文件夹名

将当前目录添加到缓冲区
git add .


3
git commit 
它用来将暂存区里的修改正式打包保存（存档）到本地仓库的命令。
每次执行这个命令，Git 都会生成一个唯一的快照（版本号），并记录下你这次修改的说明信息。

将暂缓区的内容存档到本地仓库
git commit -m "修改说明"
必须写上修改说明，要不然无法存档。

4
git status
这个指令可以检查文件中，已经修改的文件是否在暂缓区内。

远程仓库
{///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
1
克隆远程仓库
git clone ssh地址 <目标路径> (拉取远程仓库)
git clone http地址 <目标路径>(拉取远程仓库)

注意
git clone要求目标路径必须是一个不存在的目录或者一个空目录，否则会拒绝操作以防止意外覆盖已有数据。

2
关联远程仓库
git remote add origin 远程仓库的http地址

将本地仓库的项目上传到远程仓库
git push -u origin <分支名>

查看git 关联的远程仓库
git remote -v 

删除现在git关联的远程仓库
git remote rm origin 

将文件强制推送到远程仓库并覆盖
git push -f origin main
强制推送会直接覆盖远程仓库的历史记录，导致远程分支上别人（或你之前）提交的代码被丢弃。在执行前，强烈建议先备份当前项目。
}///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

1
设置git 的全局用户名

2

3
生成一对密钥
ssh-keygen -t rsa -b 4096 -C "邮箱地址" 

查看公钥
cat ~/.ssh/id_rsa.pub 

小知识
生成密钥后，会生成一个公钥(public key)和一个私钥(identification)，公钥发给远程服务器，私钥留给自己。
远程服务器会用手里的公钥去验证你手里的私钥，如果匹配，那就通过。

6
告诉git 去使用系统自带的证书库
git config --global http.sslBackend schannel 

7
如果写的git代码太长，你可以使用 \+ 回车键， 来使代码换行
示例:git clone \
 git@codeserver.youkeda.com:keqing222/f2-5-1-6.git
