git add命令
{/////////////////////////////////////////////////////////////////////////////////////////////////////////////
git add
它的作用是将当前工作目录下的所有变动（包括新增、修改和删除的文件）一次性添加到 Git 的暂存区（Staging Area）。

将单个文件添加到缓冲区
git add 文件名.文件类型

将多个文件添加到缓冲去
git add 文件名.文件类型 文件名.文件类型

将一个目录添加到缓冲区
git add 文件夹名

将当前目录添加到缓冲区
git add .
{/////////////////////////////////////////////////////////////////////////////////////////////////////////////





git commit 命令
{/////////////////////////////////////////////////////////////////////////////////////////////////////////////
git commit 
它用来将暂存区里的修改正式打包保存（存档）到本地仓库的命令。
每次执行这个命令，Git 都会生成一个唯一的快照（版本号），并记录下你这次修改的说明信息。

将暂缓区的内容存档到本地仓库
git commit -m "修改说明"
必须写上修改说明，要不然无法存档。
{/////////////////////////////////////////////////////////////////////////////////////////////////////////////




git push命令
{/////////////////////////////////////////////////////////////////////////////////////////////////////////////
将本地仓库的项目上传到远程仓库
git push -u origin <分支名>

将文件强制推送到远程仓库并覆盖
git push -f origin main
强制推送会直接覆盖远程仓库的历史记录，导致远程分支上别人（或你之前）提交的代码被丢弃。在执行前，强烈建议先备份当前项目。
{/////////////////////////////////////////////////////////////////////////////////////////////////////////////

git命令生成一对ssh密钥, 查看git的ssh密钥
{/////////////////////////////////////////////////////////////////////////////////////////////////////////////
git命令生成一对密钥
ssh-keygen -t rsa -b 4096 -C "邮箱地址" 
这个命令会生成两个钥匙，一个是公钥，一个是私钥，公钥发给远程服务器，私钥留给自己。

git命令查看公钥
cat ~/.ssh/id_rsa.pub 

公钥和私钥的作用
远程服务器会用手里的公钥去验证你手里的私钥，如果匹配，那就通过。
